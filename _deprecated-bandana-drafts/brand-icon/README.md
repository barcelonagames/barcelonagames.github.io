# Barcelona Games — Bandana Logomark

The bandana is THE brand symbol. A folded headband with a knot + two tails.
Master files are SVG (infinitely scalable, recolorable). PNGs are 1024px.

## Files
- `bandana_ink.svg` — **PRIMARY**: dark-green ink band + orange knot. Use on cream/light.
- `bandana_ink_solid.svg` — one-color version (stamps, embossing, single-color print).
- `bandana_orange.svg` — orange monochrome.
- `bandana_navy.svg` — navy band + yellow knot (classic brand palette).
- `bandana_white.svg` — reversed, for dark backgrounds / over photos.
- `appicon_{cream,ink,orange}.svg` — rounded-square app icons (social avatar, app stores).
- `team_{red,gold,green,blue,purple}.svg` — one per team (Triomf, Sagrada, Güell, Tibidabo, Forum).
- `lockup_horizontal.png` — mark + "Barcelona Games" serif wordmark + tagline.
- `favicon.ico`, `favicon_{16,32,180}.png` — web favicons / apple-touch icon.

## Colors
- Ink (green) `#13332A` · Orange `#E8551F` · Navy `#00174D` · Yellow `#F2A809` · Cream `#F7F1E6`

## Clear space & min size
- Keep clear space ≥ the knot's width on all sides.
- Min size: 24px (mark only). Below that use the solid one-color version.
